# Rednote 工程约定

## 产品边界

第一版交付账号、图文笔记、首页、收藏、搜索，以功能规格中的四个用户故事验收。将新需求写回规格，再调整技术方案与任务。

## 数据一致性

MySQL 保存业务事实。笔记与对应的索引变更在同一事务提交。搜索中断时，业务写入和浏览独立运行。搜索重试必须保留已提交的最新编辑和删除状态。

## 验收与交付

每个可独立审阅的部分通过一个 PR 交付，说明关联任务和实际验证结果。核心搜索验收使用真实 MySQL 与 Elasticsearch，区分健康空结果和故障，并记录恢复时间。本地演示只使用可公开的样本账号和图文。

版本 1.0.0，生效于 2026-11-21。变更验收口径时同步更新功能规格和对应测试。
