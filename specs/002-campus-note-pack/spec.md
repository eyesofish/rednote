# 校园图文包 · 交付规格

内容作者交付离线 ZIP，收件人预览、校验并按需导入页间。首批是五个主题各两篇的样稿，样稿确认后扩展为各二十篇。正式包中的前十个编号沿用已确认的样稿。配图来源和搜索答案随包保留。

1. **作者交付。** 交接包可脱离仓库打开，含十篇完整图文、离线预览、100 行工作表及任务单。样稿有一组标题与正文的成对匹配，正式包有五组与一个零匹配词。
2. **静态校验。** 校验阶段不依赖数据库。检查 UTF-8 CSV、编号、主题配额、图片文件、来源，以及每个关键词实际匹配的笔记编号。建议的正文字数、图片比例和目标体积作为编辑提示。
3. **运营导入。** 收件人指定作者，用稳定编号导入。使用与正常发布相同的笔记、图片与搜索待办事务。重复执行、从样稿扩展到正式包均保留已导入笔记的身份；数据不一致时报告冲突。
4. **搜索验收。** 用包编号映射到实际笔记 ID，核对每组标题优先、仅正文命中排第二、零匹配为空。索引故障与没有搜索结果分别报告。

实现顺序为图文与交接包、离线校验与导入、独立 Compose 环境的发布和搜索验证。既有公开业务接口继续使用同一协议。
